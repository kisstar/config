# 配置管理增

配置管理工具包含五个核心功能：配置漂移检测、更新命令、健康检查、预览模式和卸载功能，以降低维护成本并提升用户体验。

## 文件结构

```
config/
├── lib/bin/
│   ├── install.sh
│   ├── main.sh             # 添加新命令路由
│   ├── log.sh
│   ├── util.sh             # 工具函数
│   ├── fs.sh
│   ├── drift.sh            # 配置漂移检测
│   ├── update.sh           # 更新命令
│   ├── doctor.sh           # 健康检查
│   ├── uninstall.sh        # 卸载功能
│   └── modules/
│       ├── vim.sh          # 修改：支持 DRY_RUN、记录安装
│       ├── git.sh          # 修改：支持 DRY_RUN、记录安装
│       ├── npm.sh          # 修改：支持 DRY_RUN、记录安装
│       ├── eslint.sh       # 修改：支持 DRY_RUN、记录安装
│       └── tmux.sh
├── .installed_modules      # 安装记录文件（gitignore）
└── .backup/                # 备份目录（gitignore）
```

## 使用方式示例

```bash
# 安装
sh -c "$(curl ...)" -- vim

# 预览安装
sh -c "$(curl ...)" -- vim --dry-run

# 更新
$HOME/.ks-config/lib/bin/update.sh

# 检查健康
$HOME/.ks-config/lib/bin/doctor.sh

# 检查漂移
$HOME/.ks-config/lib/bin/drift.sh

# 卸载
$HOME/.ks-config/lib/bin/uninstall.sh vim
```
